SkillPointe Match · Architecture

Key User Flows

The three role journeys the design must serve. Green steps are the moments of value (ranked matches, candidate shortlist, platform insight).

Applicant — find & act on a match

Sign up
→
Setup: program · location · dates
→
Ranked matches
→
Open match · see strengths / gaps
→
Set interest / apply
→
Plan with AI · message employer
Interest + apply-click log to engagement_events. Planning chat is job-focused.

Employer — surface & reach candidates

Invited · sign in
→
Post a job
→
Ranked applicants + AI priority
→
Draft / send outreach
→
Message · mark hired
→
Analytics funnel
Posting a job triggers a fire-and-forget match recompute. Outreach + hires recorded for analytics.

Admin — monitor & tune the platform

Sign in
→
Dashboard KPIs + match quality
→
Browse applicants / employers
→
Job map by geography
→
Engagement analytics
→
Test matches for any applicant
Admin is read-only over employer surfaces; all admin mutations are audit-logged.
