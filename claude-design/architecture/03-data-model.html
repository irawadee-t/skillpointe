SkillPointe Match · Architecture

Data Model

Key tables behind the UI. Scores live in matches; per-dimension detail in match_dimension_scores; activity in engagement_events. Postgres via Supabase.

TablePurpose
user_profilesAuth bridge — links auth.users → app role (admin / applicant / employer)
applicantsApplicant profiles (program, location, credentials, availability, preferences)
employers / employer_contactsCompany profiles + contacts
jobsJob postings (scraped + imported + manually created); city/state, family, pay, requirements
matchesbase_fit_score, policy_adjusted_score, eligibility_status, match_label, top_strengths, top_gaps, required_missing_items, recommended_next_step, confidence_level
match_dimension_scoresPer-dimension breakdown (9 dimensions)
saved_jobsApplicant interest per job: interested / applied / not_interested
engagement_eventsActivity log: interest_set, apply_click, dm_sent, outreach_sent, hire_reported …
conversations / direct_messagesApplicant ↔ employer DMs; unread counts; polled every 5s
employer_outreach / hire_outcomesOutreach intent/sent + reported hires (employer analytics funnel)
extracted_applicant_signals / extracted_job_signalsLLM extraction results
chat_sessions / chat_messagesApplicant AI planning chat (job-focused sessions)
policy_configs / review_queue_items / audit_logsScoring config, admin review queue, auditable admin actions
