SkillPointe Match · Architecture

Information Architecture

A three-role labor-market recommendation platform — Admin (SkillPointe staff), Applicant (scholar/trainee), and Employer. The product is continuous ranking + explanation of skilled-trades jobs, not batch matching. Public marketing & auth shell wraps three role-gated dashboard areas.

The matching pipeline (product core)

Layer 1 · deterministic
Base fit estimation
5 hard gates (job family, credentials, readiness, geography, minimums) + 9 weighted dimensions, blended 75% structured / 25% semantic. A failed gate caps the score.
Layer 2 · policy
Policy reranking
Adjusts ordering / visibility only. Stored separately as policy_adjusted_score — never merged into base fit.
Layer 3 · LLM
Interpretation
Extraction, verification, explanation, planning chat, AI candidate prioritisation. Supports the ranking, never overrides it.
UI principle: hard-gate failures and gaps are surfaced, never hidden inside an opaque score. Geography is first-class across gates, scoring, and explanation.
